# Practical Python Business Tools

A collection of practical Python tools designed to solve
small-business and operational problems.

## Project status

Initial development: workspace setup.

## Requirements

- Python 3.11 or newer
- Git

## Setup

Clone the repository:

    git clone YOUR_REPOSITORY_URL
    cd practical-python-business-tools

Create a virtual environment:

    python -m venv .venv

Activate on Windows PowerShell:

    .venv\Scripts\Activate.ps1

Install dependencies:

    python -m pip install -r requirements.txt

## Run

    python src/business_tools/main.py

Tests

    python -m pytest -v
